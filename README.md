# 🌍 Countries App - 🚧 On going

A countries app built as a project in class for the **React Advanced course** at Business College Helsinki.  
With this app, you can view different countries and their information such as currency, population, languages and weather. The site includes user log in and profile. You can favorite countries and view them at favorite page.

🌐 Live Demo will be here

## ✅ Features

* Display countries with information 
* 'More info' page with weather data (external API) and other country details
* Navigation with React router 
* User authentication with Google & Supabase
* Edit your profile 
* Searchbar to search countries by name and dropdown menu to display coutries by continent 
* Add countries to favorites and view them at page (Only when logged in)
* Adding later: Mobile responsivness and design fix


## 🛠️ Tech Stack
* Next.js
* Redux
* MUI 
* Supabase
* Google
